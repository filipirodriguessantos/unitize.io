01 / Arquitectura

Operación de agentes, con contexto.

Una interfaz para seguir el trabajo. Un entorno para ejecutarlo. Un historial para entender lo que ocurrió.

01

Proyectos y permisos

Cada entrega tiene su contexto. El prototipo local ya organiza las ejecuciones por proyecto, con acceso de administrador, operador o lector.

02

API y cola

La solicitud se valida antes de entrar en la cola. Los límites de trabajo pendiente ayudan a controlar la carga sin ocultar el estado de la ejecución.

03

Worker y contenedor

El worker reserva la solicitud y ejecuta la versión elegida. La demostración Docker utiliza una imagen fijada por ID y límites de recursos.

04

Eventos y resultado

Consulta entradas, salidas y eventos registrados. Revisa la espera en cola y el procesamiento, y exporta una ejecución en JSON.

Hoy en el prototipo

Próximas etapas

02 / Cómo funciona

Tú traes tu agente. Unitize se encarga de la operación.

Un recorrido sencillo desde tu código hasta una operación trazable. El soporte inicial se desarrolla con un agente de demostración propio.

  1. 01

    Prepara una versión

    Empaqueta el agente y define su contrato de entrada y salida. La propuesta es conservar tu código y tu framework.

  2. 02

    Define el contexto

    Asocia la ejecución a un proyecto y elige quién puede operar. Establece límites antes de aceptar nuevas solicitudes.

  3. 03

    Ejecuta y supervisa

    Consulta la cola, el estado y los eventos. Cancela solicitudes que aún no hayan comenzado y sigue el tiempo de procesamiento.

  4. 04

    Comprende y mejora

    Usa el historial y el JSON exportado para investigar fallos y hablar con el equipo sobre la próxima versión.

03 / Soluciones

Una base. Diferentes entregas.

Desde la primera demostración hasta la operación de clientes, con etapas claras.

01

Integradores

Una base operativa para conectar entregas hechas con herramientas diferentes, sin crear un panel nuevo para cada piloto.

02

Equipos internos

Una referencia común para desarrollo y operaciones: permisos, cola y registros del procesamiento.

03
