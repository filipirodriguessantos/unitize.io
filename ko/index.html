01 / 아키텍처

맥락을 갖춘 에이전트 운영.

작업을 살펴보는 인터페이스, 작업을 실행하는 환경, 결과를 이해하는 이력.

01

프로젝트와 권한

각 구축에는 고유한 맥락이 있습니다. 로컬 프로토타입은 실행을 프로젝트별로 정리하고 관리자, 운영자, 조회자 권한을 제공합니다.

02

API와 대기열

요청은 대기열에 들어가기 전에 검증됩니다. 대기 작업 제한으로 부하를 관리하면서 실행 상태를 확인할 수 있습니다.

03

워커와 컨테이너

워커가 요청을 맡아 선택한 버전을 실행합니다. Docker 데모는 고정된 이미지 ID와 자원 제한을 사용합니다.

04

이벤트와 결과

입력, 출력, 기록된 이벤트를 확인하세요. 대기 시간과 처리 시간을 검토하고 실행을 JSON으로 내보낼 수 있습니다.

현재 프로토타입
Python Docker

로컬 Python 실행, Docker 데모 실행, 프로젝트 이력과 초기 접근 제어.

다음 단계

고객 에이전트 통합, 운영 환경용 로그인, 예산 정책을 준비합니다. 기술 검증이 진행됨에 따라 파일럿을 시작할 예정입니다.

02 / 작동 방식

에이전트를 가져오세요. 운영은 Unitize가 맡습니다.

코드에서 추적 가능한 운영까지 이어지는 간단한 흐름입니다. 자체 데모 에이전트를 통해 초기 지원을 개발하고 있습니다.

  1. 01

    버전 준비

    에이전트를 패키징하고 입력 및 출력 규약을 정의하세요. 기존 코드와 프레임워크를 유지하는 것이 목표입니다.

  2. 02

    맥락 설정

    실행을 프로젝트에 연결하고 운영할 사람을 선택하세요. 새 요청을 받기 전에 제한을 설정하세요.

  3. 03

    실행 및 추적

    대기열, 상태, 이벤트를 확인하세요. 시작되지 않은 요청을 취소하고 처리 시간을 검토하세요.

  4. 04

    이해 및 개선

    이력과 내보낸 JSON으로 실패 원인을 조사하고 팀과 다음 버전을 논의하세요.

03 / 솔루션

하나의 기반, 다양한 구축 사례.

첫 데모부터 고객 운영까지, 명확한 단계로.

소프트웨어 개발사

고객에게 제공하는 에이전트의 운영을 정리하세요. 프로젝트를 분리하고 버전을 고정하며 각 실행의 이력을 확인하세요.

01

통합 업체

파일럿마다 새 대시보드를 만들지 않고도 다양한 도구로 구축한 솔루션을 운영하는 공통 기반입니다.

02

사내 팀

개발팀과 운영팀이 함께 참고하는 권한, 대기열, 처리 기록.

03

현 단계에서는 임의 코드 실행이나 운영 환경 수준의 격리를 보장하지 않습니다. 통제된 파일럿을 통해 제공 범위를 넓힐 예정입니다.
