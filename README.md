# Unitize.io

Landing page oficial da Unitize: uma plataforma em desenvolvimento para operar agentes com versões definidas, limites e histórico por projeto.

- **Site:** [unitize.io](https://unitize.io/)
- **Contato:** [filipirodrigues@unitize.io](mailto:filipirodrigues@unitize.io)

Este repositório contém o site público em HTML, CSS e JavaScript, com 15 idiomas e formulário de interesse conectado a uma API separada. O código da plataforma não faz parte deste repositório.

## Visualização local

Na pasta deste repositório, execute:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Abra [localhost:8080](http://localhost:8080/). O servidor local exibe os arquivos; o cadastro público depende da API e dos domínios autorizados.
