01 / Архитектура

Работа агентов с контекстом.

Один интерфейс для наблюдения за работой. Среда для выполнения. История, чтобы понять, что произошло.

01

Проекты и права доступа

У каждой поставки свой контекст. Локальный прототип уже организует запуски по проектам с правами администратора, оператора или читателя.

02

API и очередь

Запрос проверяется перед постановкой в очередь. Ограничения ожидающих задач помогают управлять нагрузкой, сохраняя видимость статуса.

03

Воркер и контейнер

Воркер резервирует запрос и выполняет выбранную версию. Демонстрация Docker использует образ с закреплённым ID и ограничениями ресурсов.

04

События и результат

Просматривайте входные данные, результаты и записанные события. Проверяйте ожидание и обработку, экспортируйте запуск в JSON.

Python Docker

Локальное выполнение Python и демонстрационного Docker, история по проектам и начальные средства контроля доступа.

Следующие шаги

Интеграция клиентских агентов, вход для производственной среды и бюджетные политики. Пилоты откроются по мере технической проверки.

02 / Как это работает

Вы приносите агента. Unitize управляет его работой.

Простой путь от вашего кода к отслеживаемой работе. Начальная поддержка разрабатывается на нашем собственном демонстрационном агенте.

  1. 01

    Подготовьте версию

    Упакуйте агента и определите контракт входа и выхода. Цель — сохранить ваш код и фреймворк.

  2. 02

    Определите контекст

    Свяжите запуск с проектом и выберите, кто может им управлять. Установите ограничения до приёма новых запросов.

  3. 03

    Запускайте и наблюдайте

    Просматривайте очередь, статус и события. Отменяйте ещё не начавшиеся запросы и следите за временем обработки.

  4. 04

    Понимайте и улучшайте

    Используйте историю и экспортированный JSON, чтобы изучать ошибки и обсуждать следующую версию с командой.
